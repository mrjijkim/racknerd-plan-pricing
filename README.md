硬件层面也要心里有数：

- 标准 KVM 套餐用较老的 Xeon E5/E3 平台，单核 Geekbench 5 跑分 400–600，对比 Vultr 高频机型的 1100 以上差距明显；预算高一点的可以看 AMD Ryzen NVMe 系列，架构和硬盘都更新；
- CPU steal（被邻居虚拟机抢走的算力）偶尔到 5–10%，高峰期有体感卡顿；
- 内存不超售，分给你多少就是多少，这是它在低价市场里比较实在的一点；
- 磁盘是普通 SSD（非 NVMe），随机读写 100–200 MB/s，跑代理、建站没问题，高频数据库读写会遇到瓶颈。

2026 年一篇深度评测给它的综合分是 4.4/5，扣分点主要在晚高峰速度和流媒体解锁——和上面的结论对得上。
